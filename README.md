# 🐟 摸鱼计时排行榜

一个**多人实时联机**的摸鱼计时 + 排行榜网页应用。所有人打开同一个链接，
共享同一份数据，谁摸得久谁上榜，第一名戴皇冠，垫底被吐槽。

> 拒绝严肃商务风，主打年轻化、搞怪、自嘲。配色马卡龙撞色，圆角卡片，emoji 乱飞。

---

## ✨ 功能清单

- **多人实时共享**：基于 WebSocket，服务端持有全局状态，任意一人开始/暂停/结束，所有人榜单秒级刷新。
- **自定义身份**：起昵称、选搞怪 emoji 头像，或上传图片（自动压缩到 96px，不拖慢页面）。
- **摸鱼计时器**：开始 / 暂停 / 结束 三连击，累计总时长与今日时长。
- **排行榜**：按累计时长自动排序；第一名 👑 皇冠闪光特效；垫底随机吐槽标签（如"劳模叛徒，毫无摸鱼灵魂"）。
- **趣味成就**：根据总时长解锁「摸鱼萌新 / 带薪发呆 / 带薪闲逛 / 摸鱼大师 / 摸鱼宗师 / 摸鱼之神」等称号。
- **数据重置**：一键清空所有人记录（带二次确认）。
- **额外交互**：时长数字实时滚动、排名变动刷新动画、切换用户入口、底部趣味提示语轮播（"小心老板突袭！""摸鱼有益身心健康（假的）"）。
- **适配电脑 + 手机**：响应式布局，手机端自动单列堆叠。

## 🚀 快速开始（本地运行）

环境要求：**Node.js 16+**（已装 `npm` 即可）。

```bash
# 1. 安装依赖（只需一个 ws 包）
npm install

# 2. 启动服务
npm start
# 或： node server.js

# 3. 浏览器打开
http://localhost:3000
```

打开后输入昵称、选头像即可开始摸鱼。
**想看多人效果**：再开一个浏览器标签页 / 无痕窗口 / 手机同一 WiFi 打开同一地址，两边会实时同步。

> 自定义端口：`PORT=8080 npm start`

## 🌐 多人共享方案

### 方案 A：同一局域网（最简单）
1. 在「主机」上按上面步骤启动服务。
2. 查主机内网 IP（Windows：`ipconfig` 看 IPv4；Mac：`ifconfig`）。
3. 同一 WiFi 下的其他人访问 `http://<主机IP>:3000` 即可加入。

### 方案 B：公网部署（任何人都能访问）
把整个文件夹丢到任意支持 Node.js 的平台即可（无需数据库）：

- **Render / Railway / Fly.io / Koyeb / 腾讯云 CloudBase / 阿里云 FC** 等：
  新建一个 Node 项目，构建命令 `npm install`，启动命令 `npm start`（或 `node server.js`），
  端口读取环境变量 `PORT`（这些平台会自动注入）。
- **内网穿透**（不买服务器也能公网访问）：
  - `npx localtunnel --port 3000`
  - 或 `ngrok http 3000`
  - 或 `frpc` 自建隧道
  拿到公网地址后发群里，全员一起摸鱼。

> 数据持久化：服务端会把全员记录写入 `data.json`，重启不丢；跨天然自动清零「今日时长」。

## 🧠 实现要点（给想改的同学）

- **共享数据**：服务端 `state.users` 以用户 id 为 key 存全员状态；计时状态「服务端权威」
  （`running` / `runStart` 由服务端记录），避免各客户端各算各的导致榜单不一致。
- **实时同步**：任意事件（加入/开始/暂停/结束/重置）触发一次全员广播；另加每秒心跳广播保证滚动与跨天清零生效。
- **时钟校正**：客户端用服务端下发的时间戳校正本机时钟漂移，计时显示不偏。
- **头像上传**：前端用 canvas 裁成正方形并压到 96px JPEG，控制数据包大小。
- **安全**：昵称做了 HTML 转义，避免 XSS。

## ❓ 常见问题

- **Q：关掉网页计时还在算吗？**
  A：算。计时在服务器端进行，只要你点过「开始」没点「结束/暂停」，服务器持续累计。
  重新打开页面会用同一身份（localStorage 记住 id）继续显示。
- **Q：想彻底重置？**
  A：点排行榜底部「🧹 清空所有人记录」，二次确认后全员归零。
- **Q：数据存哪？**
  A：`data.json`（项目根目录），纯 JSON，可手动备份/删除。

## 🔗 临时公网入口（不用部署就能分享）

直接用 `localtunnel` 把本地服务暴露到公网，任何人点链接就能进，多人实时同步照常：

```bash
# 先 npm start 起服务，另开一个终端：
npx localtunnel --port 3000
# 输出 your url is: https://xxxx.loca.lt  ← 这就是公网地址，丢群里
```

- ✅ 已验证：`HTTP 页面` 与 `WebSocket 实时同步` 经公网均可正常工作。
- ⚠️ 临时性质：链接依赖运行进程，进程/网络中断即失效；每次重开子域名会变。
- ⚠️ 浏览器首访偶尔会弹 localtunnel「点击继续」验证页，点一下就进应用。
- 想要**固定、长期、稳定**的公网地址 → 用上方「方案 B」部署到 Render / Railway 等平台（本项目无需数据库，`npm start` 即可）。
